# 🌍 Travel Destinations REST API (Python)

A simple and clean **RESTful API** built using **Python, Flask, and SQLAlchemy** that allows users to manage travel destinations with full **CRUD operations**.

This project is beginner-friendly and demonstrates backend fundamentals such as API design, database integration, and Git version control.

---

## 🚀 Features

- Create, Read, Update, and Delete (CRUD) travel destinations
- RESTful API structure
- SQLite database integration using SQLAlchemy ORM
- JSON request & response handling
- Clean project structure
- Suitable for learning and interviews

---

## 🛠️ Tech Stack

- **Programming Language:** Python  
- **Framework:** Flask  
- **Database:** SQLite  
- **ORM:** Flask-SQLAlchemy  
- **Tools:** Git, GitHub, Postman / Thunder Client
